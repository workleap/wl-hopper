# Shadcn Extension

> Components ported from the shadcn/ui React Aria registry and styled with Hopper design tokens. They fill the gap when a design calls for a component shadcn has and Hopper does not. Their API is React Aria's verbatim and they are styled through `className`, not style props — the opposite of `@hopper-ui/components` on both counts. A component name lives in exactly one package, so if it exists in `@hopper-ui/components`, use that one.
